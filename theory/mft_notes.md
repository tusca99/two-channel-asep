# MFT Phase Boundaries — Pronina & Kolomeisky (2007)

Two-channel ASEP with narrow entrances. Effective entrance rates (eq 2):

    α1 = α(1 − m1),   α2 = α(1 − pL)

where m1 = density at site 1 of lane 2, pL = density at site L of lane 1.

## Symmetric phases

**MC** (J1 = J2 = 1/4): exists for β > 1/2 and α1 > 1/2, i.e.

    α > 2β/(4β − 1)          (eq 10)

**LD** (J1 = J2 = α1(1 − α1)): self-consistency (eq 12)

    α1 = [α + β − √((α+β)² − 4α²β)] / (2α)

exists for α < 2β/(4β − 1)  (eq 13).

**HD**: requires α > 1, never realized with narrow entrances.

## Asymmetric phases

**HD/LD** (J1 = β(1−β), J2 = α2(1−α2)): exists for

    β < α/(1 + α + α²)        (eq 23),   β < 1/2

**LD/LD** (both LD, different densities): exists for

    α/(1 + α + α²) < β < [α(1−2α) + 2α√(α²−α+1)] / 3   (eq 33)

## Phase diagram (α, β) summary

| Region | Condition |
|--------|-----------|
| MC     | β > 1/2 and α > 2β/(4β−1) |
| LD     | α < 2β/(4β−1) |
| HD/LD  | β < α/(1+α+α²) |
| LD/LD  | α/(1+α+α²) < β < [α(1−2α)+2α√(α²−α+1)]/3 |

Transitions: LD↔MC and LD↔LD/LD are continuous; HD/LD↔LD/LD is first order.
